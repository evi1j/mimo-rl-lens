# MiMo-V2.6 RL 实时训练看板

本地看板，实时展示小米 MiMo-V2.6 的强化学习训练过程。右侧「实时解说」栏会解释当前数据在发生什么，并附带知识点讲解。

## 运行条件

- **Node.js 22.5 或更高**（推荐 22.x LTS）
  - 原因：看板用 SQLite 存档，22.5 起 Node 自带 `node:sqlite`。
  - **低于 22.5 也能跑**：会自动换用 `node-sqlite3-wasm`（纯 WebAssembly）。
    压缩包里已经带上这个包，通常不用管；万一启动日志提示缺它，在本目录执行
    `npm install node-sqlite3-wasm` 即可。
  - 两个都凑不出来时：看板照常显示，只是历史不落盘（搜索解说、导出 CSV 不可用）。
- **能访问 https://mimo.xiaomi.com/rl/** —— 小米官方公开接口，需要外网。
- 8787 端口空闲。
- **通常不需要 `npm install`** —— 只有 Node 太旧、要装 wasm 兜底包时才需要。

## 启动

| 系统 | 方式 |
|---|---|
| macOS / Linux | 双击 `start.command`（首次可能需右键 → 打开），或终端执行 `./start.command` |
| Windows | 双击 `start.bat` |
| 任意平台 | 在本目录执行 `node src/server.js` |

启动后自动打开 http://127.0.0.1:8787 。关闭终端窗口即停止服务。

**换端口**：编辑本目录下的 `config.json`，改 `server` 段，保存后重启：

```json
{ "server": { "port": 8899, "host": "0.0.0.0" } }
```

临时换一次不想改文件，就用环境变量（优先级更高）：`PORT=8899 node src/server.js`。

## 用其他设备访问（手机 / 另一台电脑）

服务**默认监听 `0.0.0.0`（所有网卡）**，所以同一网络内的其他设备可以直接访问，
不需要改配置。步骤：

1. 查这台电脑的 IP：
   - macOS：系统设置 → 网络 → Wi-Fi → IP 地址，或终端执行 `ipconfig getifaddr en0`
   - Windows：`ipconfig`，找「IPv4 地址」
   - Linux：`ip addr`
2. 在另一台设备的浏览器打开 `http://<上面的IP>:8787`。

若通过虚拟局域网（异地组网）访问，用该网络分配给这台电脑的 IP 即可，原理相同。

**访问不到时排查**：确认服务正在运行（本机访问 http://127.0.0.1:8787 应正常）→
确认两台设备在同一网络 → 检查系统防火墙是否拦截了入站连接（macOS 首次运行可能会弹窗询问，选「允许」）→ 确认 IP 没填错。

**只想本机访问**（更安全）：启动时指定 `HOST=127.0.0.1 node src/server.js`。

## 目录结构

```
server.js        主服务：反代上游接口，提供 /api/*
paths.js         根目录探测（开发时源码在 src/ 下，这里已摊平到根）
sqlite.js        SQLite 驱动适配（内置 node:sqlite / wasm 兜底）
store.js         SQLite 存档层（指标 + 解说）
llm.js           AI 解说客户端（默认关闭）
config.json      AI 配置

start.command    macOS / Linux 启动脚本（双击即可，它会自己判断入口在哪）
start.bat        Windows 启动脚本
data/            运行时自动生成的数据库（首次启动创建，可删）
```

## 页面模块

顶部有三个标签页：**总览 / 指标库 / 关于**。

**总览页**

- **概览卡片** —— 两个 run 的当前步数、成绩、进度、花费、训练批大小 × 采样数、相对首步的涨幅
- **核心指标** —— 主成绩曲线 `dynsam/avg@n`
- **离线评测** —— 遍历 `api/benchmarks` 渲染全部基准（当前 3 个：DeepSWE v1.1、
  In-house Coding Bench、AutomationBench v1.0.6），每个基准一张卡片，含中英文标题、
  两个 run 的最新分与累计涨幅、随训练步变化的折线图、以及中文说明。
  基准数量由接口决定，上游新增基准会自动出现，无需改代码
- **官方公告 / 步事件流** —— trainer 的中断与恢复记录
- **数据源分布** —— 按任务类别统计的活跃数据集
- **训练样本构成** —— 每一步真正进入训练的 prompt 来自哪些任务类别（堆叠面积图 + 明细表，
  可切「数量 / 占比」两种画法）。数据由各数据源的存量变化推导：
  `trained(t) ≈ held(t−1) + accepted(t) − held(t)`；重启后的那一步上报口径不同，会标 `≈`
- **训练指标全景** —— 官方精选的 18 项训练指标，每项配中文名与说明（鼠标悬停看全文）：
  策略熵、策略梯度损失、梯度范数、推理/训练 KL、上下文长度、交互轮数、训练 token 量、
  耗时拆解（单步/生成/训练）、零分率、满分率、基础设施故障率、活跃沙箱数、策略陈旧度等

**指标库页**

trainer 上报的全部指标（约 2000 项）按路径分层浏览：左侧树形导航逐层展开，
右侧列出该分类下的所有指标曲线。支持子串搜索与 `/正则/` 搜索，结果分页加载。
数值格式沿用上游的 `formats` 规则（耗时转小时、比率转百分比、大数千分位）。

**关于页**：项目说明与怎么看这个面板。

顶栏右侧常驻**总花费**与北京 / 洛杉矶 / 纽约 / 伦敦四地时钟。

## 看不懂指标？用讲解抽屉

页面里的数字和图表都可以点开看讲解：

- **点任意一张指标卡片** —— 打开该指标的完整讲解
- **点面板标题旁的「?」** —— 讲解这一整块面板（7 个面板都有）
- **点页面顶部的「打开看板导读」** —— 索引页，列出全部图表模块与 18 个训练指标，可逐个点开
- 讲解底部有**上一个 / 下一个**，可以在 18 个指标间按顺序看完

每个指标的讲解固定回答五个问题：

1. **这是什么** —— 它度量的量是怎么定义的
2. **这张图怎么看** —— 横轴纵轴是什么、曲线形状意味着什么、单步抖动是否正常
3. **现在的数在说什么** —— 结合实时数值计算出来的解读（不是固定文案，数据变了它也变）
4. **什么情况要警惕** —— 什么形态是异常信号
5. **相关指标** —— 点一下跳到关联指标

讲解内容放在 `public/glossary.js`，纯前端、不联网、不依赖 AI，所以离线可用。
指标库里 2000+ 个没有专门词条的指标会按路径前缀给一个类别级兜底说明。

## 右侧「实时解说」是什么

解说分两层：

**1. 规则引擎（默认，开箱可用）**
根据指标变化自动生成解说，并附带知识点。点「展开讲讲」可看到原理讲解，例如：
GRPO 的组内相对优势、`advantage=(r−mean)/std`、全对/全错时组内方差为 0 导致梯度消失、
动态采样、rollout 与 training 为什么要分离、checkpoint 存档点存了什么、
异步训练用 staleness 换吞吐的代价等。

**2. AI 增强（可选）**
接入自己的 OpenAI 兼容接口后，解说会由大模型重写得更充分。改 `config.json`：

```json
{ "llm": { "enabled": true, "baseUrl": "http://127.0.0.1:8090/v1",
           "apiKey": "你的key", "model": "模型名" } }
```

保存即生效，无需重启。AI 不可用或超时会自动回落到规则引擎，页面不会空白。

## 数据存档

每次轮询的指标与解说都写入 `data/board.db`（SQLite）。
解说栏底部有「导出 CSV」，可导出全部历史指标。

存档驱动：Node ≥22.5 用内置的 `node:sqlite`；版本更低时自动换用包里自带的
`node-sqlite3-wasm`。启动日志会写明用的哪一个。删掉 `data/` 只是清掉历史，
下次启动会重建。

## 常见问题

- **页面显示「连接失败」** —— 服务没在跑，重新双击启动脚本。
- **提示需要 Node 22.5+** —— Node 版本太低。要么升级 Node（推荐），
  要么在本目录执行 `npm install node-sqlite3-wasm` 用 wasm 兜底。
- **启动日志出现「存档不可用」** —— 同上：既没有内置 `node:sqlite`，
  也没装 wasm 兜底包。看板还能看实时数据，但历史不保存。
- **8787 端口被占用** —— 换端口：改 `config.json` 的 `server.port` 后重启，
  或临时用 `PORT=8899 node src/server.js`（环境变量优先，不用改文件）。
- **只想自己能访问** —— 把 `config.json` 里 `server.host` 改成 `127.0.0.1` 并重启。
- **图表空白 / 数据不更新** —— 检查能否访问 https://mimo.xiaomi.com/rl/ 。
- **双击 .command 提示「无法打开」** —— macOS 安全限制，右键该文件选「打开」；
  或在终端执行 `chmod +x start.command` 后再运行。
